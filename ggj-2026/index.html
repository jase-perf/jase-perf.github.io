tools & files from the talk

Here are some free resources I've created to help others get started with version control and build automation. These are all my own open-source work and I'd love to get your feedback on them.

P4 Build Machine Lite
A small build machine for jam teams and indie projects: one stdlib Python file, its own P4 workspace, and build scripts for Godot, Unity and Unreal. It builds when a P4 trigger fires, when a P4 Code Review test asks, or when you press the button, and the page goes red when someone breaks the build.
Pythongithub →
P4Godotsoon
A Perforce plugin for Godot — check out files, submit, and see what your teammates have open without leaving the editor. The repo stays private until final testing and the docs are done, then it opens up at github.com/jase-perf/P4Godot.
Godot pluginpublic shortly
P4 server in a containersoon
A containerized P4 server, for standing one up in minutes to test on, learn on, or run a jam on. Also private for now, landing at github.com/jase-perf/p4-server-docker.
Dockerpublic shortly
P4 typemap gist
A ready-made typemap covering Godot, Unity and Unreal projects plus the common 3D and audio tools. This is the file that marks art and audio as binary and exclusive-checkout, so two people cannot both edit the same PNG.
gist →
P4IGNORE gist
A P4IGNORE file for Unreal projects and the usual DCC tools, so build output, caches and editor temp files stay out of the depot. It keeps growing as people comment on it.
